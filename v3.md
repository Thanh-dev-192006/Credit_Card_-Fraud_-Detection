The main dataset (`bs140513_032310.csv`) contains **594,643 records** and **10 columns** as follows:

| Column Name | Data Type | Description |
|---|---|---|
| `step` | int64 | Simulation time step, ranging from 0 to 179 (equivalent to ~6 months, where each step ≈ 1 day) |
| `customer` | object | Unique customer identifier (e.g., `'C1093826151'`) |
| `age` | object | Customer age group: `'0'`–`'6'` (young to old), `'U'` = unknown |
| `gender` | object | Gender: `'M'` (male), `'F'` (female), `'E'` (enterprise), `'U'` (unknown) |
| `zipcodeOri` | object | Customer’s residential postal code (e.g., `'28007'`) |
| `merchant` | object | Merchant/payment acceptor identifier (e.g., `'M348934600'`) |
| `zipMerchant` | object | Merchant’s postal code |
| `category` | object | Transaction category (15 types, e.g., `es_transportation`, `es_food`, `es_health`) |
| `amount` | float64 | Transaction amount (unit: EUR), ranging from 0 to 8,329.96 |
| `fraud` | int64 | Target label: `0` = normal transaction, `1` = fraudulent transaction |
